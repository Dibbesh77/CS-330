# CS 330 Computational Graphics and Visualization Portfolio

This repository includes my CS 330 final project files. The 3D scene ZIP folder and Design Decisions document show my work with OpenGL, low-polygon objects, textures, lighting, materials, camera controls, and project organization.

## How do I approach designing software?

I approach designing software by first understanding the project requirements and then breaking the work into smaller parts. For this project, I looked at the objects I needed to create and planned how basic shapes could be combined to build a complete 3D scene. This helped me practice design skills such as choosing the right primitive shapes, organizing object placement, using textures, and thinking about how the user would move through the scene.

## How do I approach developing programs?

I approach developing programs through step-by-step progress and testing. During the milestones, I added one major feature at a time, such as camera movement, object placement, textures, and lighting. Iteration was important because I tested the program often, checked how the scene looked, and made changes when something did not appear correctly. My development process improved because I learned to keep the code more organized using manager classes, separate functions, and clear comments.

## How can computer science help me in reaching my goals?

Computer science helps me build problem-solving skills that I can use in future classes and professional work. Computational graphics and visualization taught me how code can create interactive visual environments. These skills can help me in future software development, simulation, design, and visualization projects. Professionally, this course helped me understand how graphics programming connects math, logic, user interaction, and visual design.
